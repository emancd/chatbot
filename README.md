# Chatbot

A simple and interactive chatbot built with React that responds to basic greetings and questions.

## ✨ Features

- Welcomes users with a friendly "Hello"
- Tells the current date when asked
- Says goodbye with a positive message
- Clean and responsive chat interface
- Real-time message handling with smooth scrolling

## 🛠️ Technologies Used

- React (Functional Components + Hooks)
- JavaScript (ES6+)
- CSS (Vanilla CSS for styling)
